Classes & attributes

Class / attributePurpose
.draw-wrap / .drawA fixed-size SVG. Narrow containers scroll without reducing label sizes.
.plot-binAn interval’s rectangle. Use adjacent equal-width bins on a count axis and start heights at zero.
.plot-zeroAn observed empty bin remains on the axis with an explicit zero label.
.plot-axis / .plot-grid / .draw-valueAxis, guides and exact bin counts. Label both axes and the bin boundary convention.
.plate / .plate-sourceCaption, sample size, selection criteria and data source.

Usage notes

Use a histogram for numeric distribution and Bar chart for named categories. Keep all bins in numeric order, including zeros. Equal-width bins allow counts; unequal widths require frequency density so area represents frequency. State inclusive or half-open boundaries and the observed sample size. Missing observations are excluded with an explicit count, never inserted as zeros; when none were measured, use Empty. This six-caller example describes one table, not the entire project.
