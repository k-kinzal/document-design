Comparison plot

Show a before-and-after difference on one axis, with both endpoints and denominators visible.

A change with a different denominator

HTML
<figure class="plate plate-wide">
  <p><strong>How far did source coverage move?</strong></p>
  <div class="draw-wrap" role="region" aria-label="Source coverage comparison" tabindex="0">
    <svg class="draw" style="--dd-draw-width:768px" viewBox="0 0 768 220" role="img" aria-label="Source coverage: before 20 of 29 units, 68.97 percent; after 29 of 30 units, 96.67 percent. Increase of 27.70 percentage points. The denominator changed.">

Classes & attributes

Class / attributePurpose
.draw-wrap / .drawA scrolling wrapper and fixed-size SVG. Set --dd-draw-width to the viewBox width in px; author coordinates at that size.
.plot-axis / .plot-gridThe axis and supporting guides. State the domain and units with draw-note text.
.plot-spanThe connector between two observations of the same measure. It expresses a difference, not a measured trajectory.
.plot-before / .plot-pointHollow before marker and filled after marker. Both need direct labels and exact values.
.draw-value / .draw-note / .plate-sourceNumeric labels, supporting type, and the snapshot or measurement conditions.

Usage notes

Use a dumbbell for paired observations. Map x = left + (value − minimum) / (maximum − minimum) × plot width, using the same domain for every row. Include zero for percentage coverage. Name changes in denominator and use percentage points for the difference between percentages. For signed changes, keep decreases neutral unless they represent a problem; red is reserved for warnings and absence.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
