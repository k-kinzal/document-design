Lists & data / Labeled attributes

Facts

A definition list for short answers about one thing: a version, scope, or source.

Basic usage

HTML
<dl class="facts">
  <div><dt>Dataset</dt><dd>WordPress SQL catalog</dd></div>
  <div><dt>Source files</dt><dd>77 files</dd></div>
  <div><dt>Analysis scope</dt><dd>Discovered database calls in WordPress</dd></div>
</dl>

Classes & attributes

Class / attributePurpose
.factsA definition list of attributes.
dt / ddWrap each label and value in one div.

Usage notes

Give figures units. Use Definitions for longer explanations of vocabulary.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
