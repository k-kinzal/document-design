Classes & attributes

Class / attributePurpose
.draw-wrap / .drawFixed-size SVG in a scrolling region. Add tabindex="0", role="region", and an accessible name when it scrolls.
.plot-line / .plot-pointAn authored path and its observations. Straight segments interpolate; horizontal and vertical segments form a step plot.
.plot-line-alt / .plot-point-altA dashed line and hollow points for a secondary series. Pair with direct series names; color alone is insufficient.
.plot-missing / .plot-missing-labelA dashed missing interval and its visible explanation. Do not draw a connecting path across it.
.plot-axis / .plot-grid / .draw-noteNumeric axes, guides and unit labels; coordinate spacing must reflect the data domain.

Usage notes

Use a numeric, ordered horizontal domain, not category rank. Map y = bottom − (value − minimum) / (maximum − minimum) × plot height. Label a nonzero axis minimum explicitly. Use steps for counts that change at events; avoid smoothing that implies unobserved values. Split paths around missing samples, and retain isolated points. Include exact observations in a table or caption. The example uses source position, not invented timestamps.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
