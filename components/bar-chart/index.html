Classes & attributes

Class / attributePurpose
.bars / .bar-rowA semantic list and its rows. Wide lists align labels, bars, and values; narrow lists put the bar below the text.
.bar-label / .bar-value / .bar-noteThe category, exact quantity with units, and optional qualification. Long names wrap; numbers stay together.
.bar-track / .bar-fillThe common scale and proportional mark. Set --dd-bar to value / shared maximum × 100%. Use one maximum for the entire list.
.bar-track.is-missingAn unavailable measurement. Omit bar-fill and write “Not measured” in bar-value. A measured zero uses --dd-bar:0%.
.tone-*Optional category identity. The visible category name must carry the same identity without color.

Usage notes

Use for non-negative category magnitudes. Always start bars at zero and state the maximum and units. Never give a tiny value a minimum visual width or normalize each bar separately. Use Meter for shares of one whole; a table for precise lookup. Values and labels remain in HTML when printing or using assistive technology.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
