Classes & attributes

Class / attributePurpose
.draw-wrap / .drawThe fixed-size diagram and its scrolling region; use draw text roles and explicit SVG alignment attributes.
.node-action / .node-decision / .node-terminalAn action rectangle, a decision diamond, and an outcome. All share one node size and a 1.5px outline; shape identifies the role.
.edge-flow / .edge-arrowConnector paths and open arrowheads. Draw these before nodes so lines cannot cross the node labels.
.edge-labelA plain branch label. Route connectors clear of the text; do not paint a background halo around letters. Use with draw-label.
.draw-label / .draw-strong / .draw-noteNode names and explanatory text at the shared drawing type size.

Usage notes

Use for processes with choices or branches. Choose one node module for the whole figure: the full example uses 224 × 64px, 48px between rows, and 8px between arrow tips and their targets. Center every node title with draw-strong; place supporting notes outside the boxes. The index uses 96 × 40px nodes and shorter labels at the same text size. If a label needs more room, enlarge the shared module rather than one node. Put a visible condition on every branch. The generator computes coordinates and routes; this component does not run a layout engine. Graph is for dependencies; Composition’s ordered flow is for an unbranched reading sequence.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
