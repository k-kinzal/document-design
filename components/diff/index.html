Diff

Show additions, removals, and modifications through both color and explicit marks.

Basic usage

HTML
<pre class="code diff"><span class="dl diff-line-del">- public function build(): string</span>
<span class="dl diff-line-add">+ public function build(): Statement</span>
<span class="dl diff-line-mod">~ @throws QueryException</span></pre>

Classes & attributes

Class / attributePurpose
.diff / .dlA diff block and an individual line.
.diff-line-add / .diff-line-del / .diff-line-modAdded, removed, and modified lines.
.diff-run-add / .diff-run-del / .diff-run-modThe changed run within a line.
.is-added / .is-removed / .is-modifiedChange marks for cells in a listing.

Usage notes

Write +, −, and ~ in the HTML as well. The change remains meaningful after it is copied or printed.

Examples follow your system color scheme. Use ◐ in the header to try automatic, light, and dark themes.
