レイアウト / 図版と注釈

Composition

図版・キャプション・注釈を、一続きの読む順序に組みます。

図とその説明

HTML
<figure class="plate plate-full plate-side plate-unnumbered">
  <div class="plate-body">
    <h3 class="compare-title"><span class="ref ref-mark tone-teal">B</span> ペーパー</h3>
    <ol class="flow tone-teal">
      <li><span class="flow-mark" aria-hidden="true">01</span><strong class="flow-name">問い</strong><span class="flow-detail">全体をつかむ</span></li>
      <li><span class="flow-mark" aria-hidden="true">02</span><strong class="flow-name">根拠</strong><span class="flow-detail">事実をつなぐ</span></li>
      <li><span class="flow-mark" aria-hidden="true">03</span><strong class="flow-name">意味</strong><span class="flow-detail">結果を読み解く</span></li>
    </ol>
  </div>
  <figcaption>
    <p class="plate-summary"><span class="plate-label">図1.</span>ペーパーでは、主張・根拠・意味を明快な順序で読めるようにします。</p>
    <p class="sidenote">矢印は読む順序を示し、因果関係は表しません。</p>
  </figcaption>
</figure>

意味に沿ったページのラッパー

HTML
<div class="sheet sheet-wide">
  <header class="masthead">文書名</header>
  <main class="sheet-body">
    <header class="cover"><div><h1 class="cover-title">最も伝えたいこと。</h1></div></header>
    <section class="sec">
      <h2 class="label">背景</h2>
      <div class="field">説明は、そのあとに。</div>
    </section>
  </main>
  <footer class="colophon">出典とクレジット</footer>
</div>

クラスと属性

クラス / 属性用途
.plate / .plate-wide / .plate-full本文幅・図版幅・全幅から選べる、番号付きのfigure。
.plate-unnumbered生成側で本文の参照も書く場合は、図番号を明示します。
.plate-side / .plate-summary / .sidenote注釈を脇に添えるキャプション。狭い列では注釈がその下に続きます。
.plate-body / .plate-label / .plate-source罫線付きの図本体、明示的な図番号、出典や条件。
.compare / .compare-title / .compare-draw余裕があれば比較する二組を横に並べます。.compare-drawは作図時の幅を保ち、収まらなければ折り返します。
.flow / .flow-mark / .flow-name / .flow-detail番号・名前・説明からなる3段階の流れ。矢印は読む順序です。
.ref / .ref-mark図への参照。.refは番号、.ref ref-markは本文と図が共有する記号と色による識別です。
.sheet-bodymainやarticleで囲んでも、sheetの列グリッドを保ちます。

使い方の注意

キャプションと注釈はHTMLで書きます。記号やラベルはどこでも同じ意味にし、順序にはolを使います。ここでの矢印は因果関係ではなく読む順序です。plateには表やSVGも置けます。SVGの文字や印はdrawのロールを使い、狭い幅で文字を縮めずスクロールさせる場合はdraw-wrapで囲みます。

作例はシステムの配色設定に従います。ヘッダーの◐で自動・ライト・ダークを試せます。
