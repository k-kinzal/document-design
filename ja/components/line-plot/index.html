クラスと属性

クラス / 属性用途
.draw-wrap / .drawスクロール領域内の等倍固定SVG。スクロールする場合はtabindex="0"、role="region"とアクセシブルな名前を付けます。
.plot-line / .plot-point作成した経路と観測点。直線は補間を表し、水平・垂直の線分は階段図になります。
.plot-line-alt / .plot-point-alt第二系列の破線と白抜きの点。系列名を直接添え、色だけに頼らないでください。
.plot-missing / .plot-missing-label欠測区間を示す破線と説明。区間をまたぐ接続線は描きません。
.plot-axis / .plot-grid / .draw-note数値軸・補助線・単位ラベル。座標間隔はデータの範囲を反映させます。

使い方の注意

横軸はカテゴリの順位ではなく、順序のある数値にします。y = 下端 − (値 − 最小値) / (最大値 − 最小値) × 作図高さで配置します。最小値がゼロでない軸は明示します。出来事ごとに増える件数は階段で示し、未観測の値を示唆する平滑化は避けます。欠測では線を分け、孤立した点も残します。正確な観測値を表かキャプションに記します。この例はソース位置を使い、架空の時刻は使いません。

作例はシステムの配色設定に従います。ヘッダーの◐で自動・ライト・ダークを試せます。
