クラスと属性

クラス / 属性用途
.draw-wrap / .drawスクロールするラッパーと等倍の図。--dd-draw-widthをviewBoxの幅にpxで合わせ、その寸法で作図します。狭い列でも縮まず、広い列でも伸びません。
.draw-box / -toned / -alt / -open対象・識別された対象・白抜きの別状態・不在を示す面。boxは領域を意味し、<rect>専用ではありません。欠落を示す円にも同じロールを使います。
.draw-group / .draw-group-open / .draw-fill確定したまとまりを囲む細線、仮のまとまりを囲む線、トーンの淡色で塗る領域。
.draw-line / -open / .draw-guide / .draw-focus関係、未成立の関係、内容より細い補助線、図の主題を表す印。強調は加え、ほかを弱めて作りません。
.draw-arrow / .draw-defs / .draw-arrowhead共通の矢印の頭で終わる線と、そのmarker。defsは文書の枠に置きます。参照先がなくてもSVGはエラーにならず、矢印の頭だけ消えるためです。
.draw-label / -strong / -note / -value / -cap / -mono文字のロール。図のラベルも、上の段落と同じ読者が同じ距離で読む文書の文字です。
.tone-*すべての印がトーンを読みます。不在の破線を保ったまま、到達限界はwarn、欠落はtone-neutral、測定の不在はtone-dangerで示します。

使い方の注意

形は生成側、色はシステムが受け持ちます。印にfillやstrokeを直接書くと、トーン・テーマ・強制カラーに追従しません。fill="var(--dd-accent)" fill-opacity=".12"は、特にダーク時に隣の部品の淡色と一致しません。fill="none"は色ではなく形なので使えます。text-anchorとdominant-baselineはSVG属性に書きます。CSS宣言は属性に必ず勝つためです。ラベルにfont-sizeを指定せず、説明文を<text>で図内に書き込まないでください。部分に番号を付け、文章は下の凡例に置きます。Annotateを参照してください。

作例はシステムの配色設定に従います。ヘッダーの◐で自動・ライト・ダークを試せます。
