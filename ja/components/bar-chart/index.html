クラスと属性

クラス / 属性用途
.bars / .bar-row意味を持つリストと各行。広い場合は名前・棒・値を揃え、狭い場合は文字の下に棒を置きます。
.bar-label / .bar-value / .bar-noteカテゴリ、単位を添えた正確な量、任意の但し書き。長い名前は折り返し、数字は分割しません。
.bar-track / .bar-fill共通のスケールと比例する印。--dd-barを値 / 共通の最大値 × 100%で指定します。一覧全体で同じ最大値を使います。
.bar-track.is-missing取得できない測定値。bar-fillを省き、bar-valueに「未測定」と書きます。測定されたゼロは--dd-bar:0%です。
.tone-*任意のカテゴリ識別。色がなくてもカテゴリ名で同じ意味が伝わるようにします。

使い方の注意

非負の量の比較に使います。棒は必ずゼロから始め、最大値と単位を示します。微小な値に最小表示幅を付けたり、棒ごとに正規化したりしません。内訳にはMeter、正確な値の検索には表を使います。印刷や支援技術でも、値とラベルはHTMLに残ります。

作例はシステムの配色設定に従います。ヘッダーの◐で自動・ライト・ダークを試せます。
