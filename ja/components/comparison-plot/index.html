クラスと属性

クラス / 属性用途
.draw-wrap / .drawスクロールするラッパーと等倍固定のSVG。--dd-draw-widthにviewBoxの幅をpxで指定し、その寸法で作図します。
.plot-axis / .plot-grid軸と補助線。draw-noteの文字で範囲と単位を示します。
.plot-span同じ指標の二つの観測値を結ぶ線。差を表し、実測の軌跡は表しません。
.plot-before / .plot-point変更前は白抜き、変更後は塗りの印。両方に直接ラベルと正確な値を添えます。
.draw-value / .draw-note / .plate-source数値ラベル、補足の文字、スナップショットや測定条件。

使い方の注意

対応する二観測値をダンベル図で比較します。x = 左端 + (値 − 最小値) / (最大値 − 最小値) × 作図幅で、全行を同じ範囲に置きます。カバレッジの軸にはゼロを含めます。分母の変化を明示し、割合の差はパーセントポイントで示します。減少は問題を意味するとき以外は中立の色にし、赤は警告と不在のために残します。

作例はシステムの配色設定に従います。ヘッダーの◐で自動・ライト・ダークを試せます。
